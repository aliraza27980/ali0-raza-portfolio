# Ali Raza - Professional IT Portfolio

Modern, fully responsive, animated personal portfolio website for **Ali Raza**, Software Engineering student at University of Sindh, Jamshoro.

## 🚀 Features

- Clean, modern dark theme with orange accent gradients
- Smooth scroll animations (AOS)
- Fully responsive (Mobile, Tablet, Desktop)
- Sticky navigation with active section highlighting
- Preloader + Back-to-top button
- Glassmorphism cards & hover effects
- Contact form (opens email client)
- Downloadable CV
- All 14 mandatory sections from the course assignment

## 🛠️ How to Run Locally

1. Clone or download this repository
2. Open `index.html` in any modern browser
3. Or use a live server (VS Code Live Server extension recommended)

## 🌐 Deployment (Vercel / Netlify)

### Vercel
1. Push this folder to a public GitHub repository
2. Go to [vercel.com](https://vercel.com) → Import Project
3. Select your repository → Deploy

### Netlify
1. Push to GitHub
2. Go to [netlify.com](https://netlify.com) → Add new site → Import from Git
3. Deploy
